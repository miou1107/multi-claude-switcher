よくある質問

無料ですか？

はい。MIT ライセンスのオープンソースです。

パスワードや会話を見られますか？

いいえ。パソコン上で Claude Desktop が開くフォルダーを切り替えるだけです。アカウントや会話がパソコンの外に出ることはなく、通信するのは GitHub で自身のアップデートを確認するときだけです。

Anthropic 製ですか？

いいえ。Claude Desktop アプリと連携する独立したプロジェクトです。
