常见问题

收费吗？

不收费。它是 MIT 许可的开源软件。

它能看到我的密码或对话吗？

看不到。它只是切换 Claude Desktop 在你电脑上打开哪个文件夹。账号和对话都不会离开你的电脑；它只会联网到 GitHub 检查自己是否有新版本。

是 Anthropic 做的吗？

不是。这是一个独立的开源项目，配合 Claude Desktop 使用。
