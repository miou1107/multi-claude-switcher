常見問題

要付費嗎？

不用，MIT 授權的開源軟體。

它看得到我的密碼或對話嗎？

看不到。切換器只負責切換 Claude Desktop 用哪個帳號的資料夾，帳號跟對話都留在你的電腦上，只有檢查新版時會連 GitHub。

是 Anthropic 官方的嗎？

不是，這是獨立的開源專案，搭配 Claude Desktop 使用。
