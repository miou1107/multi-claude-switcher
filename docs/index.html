Questions

Is it free?

Yes. It is open source under the MIT license.

Does it see my passwords or conversations?

No. It only switches which folder Claude Desktop opens on your own computer. Your accounts and conversations never leave it; the app goes online only to check GitHub for its own updates.

Is it made by Anthropic?

No. It is an independent project that works with the Claude Desktop app.
