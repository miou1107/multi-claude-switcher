Perguntas

É grátis?

Sim. É código aberto sob a licença MIT.

Ele vê minhas senhas ou conversas?

Não. Ele só troca qual pasta o Claude Desktop abre no seu computador. Suas contas e conversas nunca saem dele; o app só se conecta para verificar as próprias atualizações no GitHub.

Foi feito pela Anthropic?

Não. É um projeto independente que funciona com o app Claude Desktop.
