Pertanyaan

Apakah gratis?

Ya. Ini open source dengan lisensi MIT.

Apakah ia bisa melihat kata sandi atau percakapan saya?

Tidak. Ia hanya mengganti folder yang dibuka Claude Desktop di komputer Anda. Akun dan percakapan tidak pernah keluar dari komputer; aplikasi hanya online untuk memeriksa pembaruannya sendiri di GitHub.

Apakah dibuat oleh Anthropic?

Bukan. Ini proyek independen yang bekerja dengan aplikasi Claude Desktop.
