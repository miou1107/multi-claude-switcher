## 為什麼需要它

Claude 桌面版一次只能登入一個帳號。下面兩種情況，你應該都碰過：

- **額度用完**：A 帳號的額度用完了，想換 B 帳號繼續寫程式。
- **公私分開**：公司的專案和自己的 Side Project，不想混在同一個帳號裡。

自己換帳號的話，要先登出，再登入另一個帳號。登入之後，左邊的對話紀錄是空的，因為紀錄跟著上一個帳號走。

**這個切換器幫你做這幾件事：**

1. **點一下就換**：點系統匣的圖示，選帳號，Claude 就換過去了。
2. **每個帳號都保持登入**：換來換去都不用再打帳號密碼。
3. **對話紀錄各管各的**：只是切換的話，不會動到任何帳號的對話紀錄。
4. **想要的話，可以讓帳號之間的對話同步**：手動同步，或在切換時自動同步，兩個帳號就看得到同一批 Code 對話。

## 安裝

先裝好 Claude 桌面版，再裝切換器。Claude 桌面版可以從 [claude.com](https://claude.com/download) 下載，也可以從 Microsoft Store 裝。

**macOS**

建議用 Homebrew 裝，一行就好：

```bash
brew install --cask miou1107/tap/multi-claude-switcher
```

也可以到[最新版本](https://github.com/miou1107/multi-claude-switcher/releases/latest)下載 `Multi-Claude-Switcher_<版本>_macos.zip`。解壓縮後，把 **Multi-Claude Switcher.app** 拖進「應用程式」。

第一次打開時，macOS 可能會擋下來，因為這個 app 沒有 Apple 的公證簽章。這時請打開「系統設定 → 隱私權與安全性」，往下捲，按「強制打開」。之後就不會再擋。

你也可以在終端機打這行，效果一樣：

```bash
xattr -dr com.apple.quarantine "/Applications/Multi-Claude Switcher.app"
```

**Windows**

到[最新版本](https://github.com/miou1107/multi-claude-switcher/releases/latest)下載 `Multi-Claude-Switcher_<版本>_windows_setup.exe`，執行它。它只裝給你自己這個 Windows 帳號，不用系統管理員權限。裝好之後，從「開始」選單打開 **Multi-Claude Switcher**。

**用 Microsoft Store 版 Claude 的人，裝好後要再設定一次**

不設定的話，你登入其他帳號時會卡住，因為 Windows 會把登入結果都送回預設帳號。

1. 點系統匣的切換器圖示，打開面板。
2. 面板最上面有一個黃色提示框，按「選擇 Multi-Claude Switcher」。
3. 按「打開 Windows 的視窗」。
4. Windows 問你「您要如何開啟此項目?」，點「Multi-Claude Switcher（推薦）」，再按「確定」。

面板出現綠色的「設定好了」，就完成了。

**自動更新**

之後有新版，切換器會在背景自己更新，不會先問你。更新好會跳一則通知。你也可以自己按「檢查更新」：已經是最新版會告訴你，有新版就馬上更新。

## 介面語言

面板會跟著電腦的語言：台灣、香港、澳門顯示繁體中文，中國大陸和新加坡顯示簡體中文，其他地區顯示英文。想自己選，到「設定」的「語言」挑一個，切換器會記住。

翻譯的只有介面上的字。帳號名稱、你自己打的字、資料夾路徑和問題回報的內容，都維持原樣。

## 怎麼用

裝好之後，找 Mac 選單列或 Windows 系統匣上的切換器圖示，點一下就會打開面板。要關掉面板，按右上角的 ×、按 Esc，或點面板外面都可以。

面板上是你的帳號清單，正在用的帳號會標「使用中」。點別的帳號就會切換：Claude 會先關掉，再用那個帳號重新打開。

切換、同步、合併、備份的時候，面板會顯示進度，做完之前不會自己關掉。做完會告訴你現在用的是哪個帳號；失敗的話，會告訴你原因。

**加入帳號**：按「重新掃描」，切換器會找出這台電腦上登入過的 Claude 帳號，勾選後就加進清單。要加一個全新的帳號，按「新增其他帳號」。

**改名、移除**：每個帳號右邊有一個扳手按鈕，裡面有「變更名稱」和「從清單移除」。

- **變更名稱**：名字會直接變成可以打字的欄位。改好按 Enter 存檔，按 Esc 取消。
- **從清單移除**：會先問你一次。移除不是刪掉，切換器只是把這個帳號的資料夾收進封存資料夾，之後要用，重新登入一次就好。下面幾種情況不能移除：
  - 清單裡只剩這一個帳號。
  - Claude 正開著這個帳號。請先切到別的帳號，再移除它。
  - 用舊版 Microsoft Store 版 Claude 的電腦，還有三種情況：這個帳號正在 Claude 裡用、切換器還沒記錄過這台電腦的帳號狀態、剛加入的帳號還在等對話搬進去。

  移除完會回到帳號清單，最上面有一行完成訊息。移除失敗，或成功但有東西沒清乾淨，會另外有一頁告訴你原因。

**設定**：可以開關「切換時自動同步」和「登入時自動啟動」，也可以選語言。「更多」裡面有帳號之間同步、備份所有帳號、開啟備份資料夾、開啟封存資料夾。設定最下面可以檢查更新、回報問題。

帳號清單最底下寫著切換器和 Claude 的版本，回報問題時會用到。點切換器的版本，可以看每一版改了什麼。

在 Windows 上，再點一次系統匣圖示也會關掉面板。面板打不開的時候，對圖示按右鍵選 **Quit**，可以結束切換器。

## 對話紀錄同步

切換帳號和同步對話是兩件事。**只切換的話，切換器不會動到任何對話紀錄。** 你只是想在帳號之間換來換去，這一節可以跳過。

想讓對話跟著你換帳號，有兩種做法：

- **帳號之間同步**（在「設定 → 更多」裡）：把一個帳號的 Code 對話複製到另一個帳號。複製前，切換器會先備份目標帳號；做完之後，你還是在原本的帳號。
- **切換時自動同步**（在「設定」裡，預設關閉）：打開之後，每次切換都會把兩個帳號的 Code 對話合在一起。久了，兩個帳號的紀錄就一樣了。第一次打開時會提醒你一次，因為合過去的對話，之後把開關關掉也不會退回來。

兩種做法遇到同一筆對話、兩邊內容不一樣時，都保留比較新的那份。另一份不會默默丟掉，切換器會告訴你。每次寫入之前，切換器都會先存一份加上時間的備份；備份失敗，這次就不寫入。

同步的只有 Code 分頁的對話清單。一般聊天的對話存在 Anthropic 的伺服器上，每個帳號各有一份，電腦這邊動不了。Code 對話的內容存在另一個地方，Claude Code 會照自己的規則清掉舊的。所以如果清單上有一筆、點進去卻是空的，那是 Claude 自己清的，切換器沒有動它，也救不回來。

## Team 帳號也能同步

Team 帳號一樣可以把對話同步進來、同步出去，不用另外設定。

Claude 存對話時分兩層：先分帳號，再分組織。切換器同步時兩層都會更新，所以同步過去的對話會出現在 Team 帳號的側邊欄。

## 回報問題

到「設定」最下面按「回報問題」，會看到一份報告，裡面是切換器知道的資訊：版本、每個帳號在電腦上的狀態、每個 log 檔最後幾行。

- 按「複製」：把報告複製起來，你可以貼到任何地方。
- 按另一個「回報問題」：把報告複製起來，再打開一個寫好標題的 GitHub 問題頁，讓你貼上。

切換器不會自己送出任何東西。你會先看到整份報告，貼上、送出都是你自己動手。

報告顯示之前，email、帳號 ID、使用者名稱和家目錄路徑就已經換成 `account-1`、`org-A` 這類代號。你還是看得出哪個對哪個，但真正的值不會離開你的電腦。換完之後，切換器會再檢查一次，看起來像 email 或帳號 ID、卻沒被換掉的字會直接塗掉。GitHub 上的問題是公開的，請放心但也留意。

## 常見問題與救援

**Q：清單上為什麼只有一個帳號？**
打開面板，按「重新掃描」，勾選你要管理的帳號。還沒登入過的帳號也會列出來：先勾選、切換過去，再在 Claude 裡登入。

**Q：重新掃描時出現「已在 Claude 桌面版登出」，而且勾不起來？**
這個帳號是在 Claude 裡登出的。登出會清掉這個帳號唯一一組登入資料，但對話都還在電腦上。按「復原」，取個名字，在跳出來的 Claude 視窗裡登入一次，對話就會回來。

想避免這種情況，加帳號時請用面板裡的「新增其他帳號」，不要在 Claude 裡登出。這樣每個帳號一開始就有自己的資料夾。

**Q：（Windows）登入其他帳號一直卡住，或登到別的帳號去？**
先更新到最新版。
如果你用的是 Microsoft Store 版 Claude，再照「安裝」那一節設定一次。
在 Windows 視窗裡點錯了也沒關係。黃色提示框會一直在，再按一次按鈕，Windows 會重新問你。
如果 Windows 都沒跳出視窗，就到「設定 > 應用程式 > 預設應用程式 > 依通訊協定選擇預設應用程式」，找到 CLAUDE，改成 Multi-Claude Switcher。

**Q：（Mac）Claude 自己更新完，怎麼跑到另一個帳號？**
先更新到最新版。
Claude 會在背景下載新版，等你一陣子沒用它，就自己關掉再打開。重新打開時沒有指定帳號，所以開的是預設帳號。
Claude 自己重開之前，會在你原本的帳號裡留一個記號。切換器看到這個記號、又看到 Claude 開在別的帳號，就會把 Claude 關掉，用你原本的帳號重開，右上角會跳一則通知。
你自己關掉 Claude、再從 Dock 打開，不會留記號，所以切換器不會幫你換回去。你在切換器裡選預設帳號，它也不會幫你換走。
如果以後 Claude 改了重開的方式、不再留這個記號，切換器就不會再幫你換回去，log 裡會寫明。

**Q：（Windows）Claude 自己更新完，怎麼跑到另一個帳號？**
Claude 更新完重新打開時沒有指定帳號，所以開的是預設帳號。切換器發現之後，會跳出視窗問你要不要換回更新前的帳號。你自己在切換器裡選預設帳號的話，它不會幫你換走。

**Q：（Windows，Microsoft Store 版）切換停下來，說 Claude 把資料搬走了？**
Microsoft Store 版的 Claude 有時會把資料搬到 `%LOCALAPPDATA%\Claude-Data`。搬過去之後，Claude 只讀新的資料夾，切換器目前還沒辦法在那裡切換帳號。
所以切換器會在關掉 Claude 之前就停下來，什麼都不動。
關掉這則訊息後會打開問題回報，原因已經幫你填好。送出報告可以幫我們早點支援這種情況。在那之前，從 claude.com 下載的 Claude 可以正常搭配切換器使用。

**Q：（Windows）面板打不開怎麼辦？**
通常是電腦少了 WebView2。對系統匣的切換器圖示按右鍵，選 **Quit**，裝好 WebView2 之後再打開切換器。Windows 10 21H2 以後的版本和 Windows 11 都已經內建 WebView2。

**Q：對話紀錄亂掉了，救得回來嗎？**
可以。到「設定 → 更多 → 開啟備份資料夾」，裡面是按帳號分開、標了時間的備份。
每個帳號保留最近五份。更舊的會先移到旁邊的 `.trash` 資料夾，放滿 30 天才刪除，所以一個月內都找得回來。你自己放進這個資料夾的檔案，切換器不會動。
如果裡面有 `tidied-` 開頭的資料夾，那是早期版本存錯位置、現在哪個帳號都打不開的對話。需要的話可以從這裡找回來。

**Q：log 在哪裡？**
在 `~/.multi-claude-switcher/logs/`。回報問題時，每個 log 的最後幾行會一起放進報告，通常這樣就夠了。

**Q：要怎麼完全移除？**

- **macOS**：刪掉 app，再刪掉 `~/.multi-claude-switcher/` 和 `~/Library/LaunchAgents/com.miou1107.multi-claude-switcher.plist`。
- **Windows**：到「新增或移除程式」解除安裝，再刪掉 `%USERPROFILE%\.multi-claude-switcher`。

移除切換器不會影響你的 Claude 帳號和資料。
